# Add your profile photo

The public LinkedIn page was readable, but did not expose a downloadable profile image through the available tools. No photo has been copied or fabricated. The top identity block currently uses KA initials.

To use your photo:
1. Save your own profile photo as assets/profile.jpg.
2. Set profilePhoto in content.js to "assets/profile.jpg".
3. Refresh index.html. The initials automatically give way to the photo when it loads.

You can also set profilePhoto to an approved public image URL, but a local file avoids expiring image links and hotlink restrictions.
